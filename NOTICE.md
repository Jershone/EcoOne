# Third-party software

OneOS deploys upstream projects as separate containers. Their code is not copied into this repository, and each keeps its own licence, trademarks, release cadence, data format, and security policy.

- Open WebUI — https://github.com/open-webui/open-webui
- Nextcloud Server — https://github.com/nextcloud/server
- Vaultwarden — https://github.com/dani-garcia/vaultwarden
- Home Assistant — https://github.com/home-assistant/core
- Navet — https://github.com/navet-app/navet
- Caddy — https://github.com/caddyserver/caddy
- MariaDB — https://github.com/MariaDB/server
- AppFlowy Self-Hosted (optional) — https://github.com/AppFlowy-IO/AppFlowy-SelfHost-Commercial

The optional AppFlowy self-host server repository has its own commercial self-host licence. It is not covered by the OneOS MIT licence.
